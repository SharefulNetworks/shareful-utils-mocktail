Installing and Configuring Mocktail Server.

Categories

Installing Mocktail Server

Pull the application from source control:

git clone https://github.com/SharefulNetworks/shareful-utils-mocktail.git

CD into root directory give the Mocktail script execution permissions:

chmod +x mocktail

Finally run the application (from the root directory):

./mocktail

Configuring Mocktail Server

Configuration details for Mocktail Server. The settings are broadly divided into two categories: General Settings and Security Settings; here all configuration settings (mandatory and optional) are defined complete with their respective data types, function, description and expected values where appropriate. All these values may be set in the config.json at the root of the project.

Name Type Category Description Accepted Values
ListeningPort Integer General The port on which the Mocktail Server will listen for incoming requests. The default is 3000. Any valid port number (e.g.1025 - 65535)
MaxConcurrentProcesses Integer General The maximum number of concurrent processes the Mocktail Server will handle. Mocktail is a request per process server thus setting this to a higher value will allow it to serve more concurrent requests but will also increase resource consumption. Any positive integer (e.g., 5, 10)
MaxHandlerProcessRuntime Integer General The maximum time (in seconds) a handler process can run before being terminated. Larger values will allow for longer running request but will also increase resource consumption. The default is 11 seconds Any positive integer (e.g., 30, 60)
LogLevel Integer General The level of logging that the Mocktail Server will use. Higher levels will provide more detailed information but will also increase the amount of data written to the console. A valid numeric log level 1: Error, 2: Warning, 3: Info, 4: Debug, 5: Trace. The default is 3 (Info).
TokenExpirationMinutes Integer Security The time (in minutes) after which system authentication token will expire. This is set to 30 minutes by default. Any positive integer (e.g., 30, 60)
AuthTokenCookieName String Security The name of the cookie used to store the authentication token. The default is "mocktail-auth-token". Any valid string (e.g., "mocktail-auth-token", "mt-auth")
EnableCORS Boolean Security Whether or not to enable Cross-Origin Resource Sharing (CORS) for the Mocktail Server. This is set to false by default. true or false
AllowedOrigins String[] Security A list of allowed origins for Cross-Origin Resource Sharing (CORS). This is set to "*" by default, allowing all origins. Note: This setting is only effective if EnableCORS is set to true. Any valid string (e.g., "*", "http://localhost:3000")
Email String Security The Admin account email address, this is set when the admin account is created and is used for login purposes.. Do not manually edit
Passphrase String Security The Admin account passphrase, this is automatically generated from the password specified at admin account creation time and is then used for login/authorization purposes. Do not manually edit
AuthenticationMethod String Security The authentication method to be used for the Mocktail Server. Only passphrase-and-token is supported at present Do not manually edit
