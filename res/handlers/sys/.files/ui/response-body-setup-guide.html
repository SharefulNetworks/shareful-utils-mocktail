Setting Bashlet Response Body.

Please see the below example for details on how to easily set a response body, in your Bashlet handler function, using the built in Bashlet JSON helper functions. 


# An example Bashlet handler function
# @route method=get path=/api/profiles
getUsers(){
  
    # The Bashlet request/response objects are automatically provided to 
    # every handler function, as argument 1 and 2 respectively.
    request="$1"
    response="$2"

    # A textual/html or JSON response can be set as the response body.
    # Here we build up a mock userProfile JSON object using the built in 
    # Bashlet JSON helper functions.
    userProfile1="{}"
    userProfile1="$(SetJSONString "$userProfile1" '.guid' 'AB36C78D87A886E868F686F86F86842A32424B24AAA42A4A')"
    userProfile1="$(SetJSONField  "$userProfile1" '.firstName' 'Giles')"
    userProfile1="$(SetJSONField  "$userProfile1" '.surname' 'Thompson')"
    userProfile1="$(SetJSONField  "$userProfile1" '.age' 35)"

    # finally we set the response body (using the built-in Bashlet function) 
    # to the userProfile JSON object which will result in the BashletEngine 
    # returning this JSON response to the client instead of the default 
    # success response.
    SetBashletResponseBody "$response" "$userProfile1"

}
