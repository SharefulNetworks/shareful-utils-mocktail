Reset Password

Unfortunately, it's not possible to reset your Mocktail password via the web interface. Please undertake the following steps to reset your password:


1) Stop the Mocktail server instance.
2) Navigate to the Mocktail root directory.
3) Open the config.json file and delete the passphrase.
4)Finally restart the Mocktail server and you will be prompted to setup new username and password authentication credentials.
