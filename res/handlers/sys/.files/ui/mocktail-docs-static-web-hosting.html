Static Web Hosting

Static Web Hosting on Mocktail Server.

Static web hosting is a feature of the Mocktail Server that allows you to serve static files (HTML, CSS, JS, images, etc.) easily, with minimum setup and config required. This is useful for hosting simple websites or other static web content.

Categories

  • Setup

Setup Static Web Hosting on Mocktail Server.

Simply go to the root of the project and navigate to target web publishing folder: res / usr / www and proceed to drag and drop all files/folders you wish to host to this directory. Then navigate to http://localhost:3333 When you visit the server root path, the Mocktail server welcome page is displayed by default, to override this behaviour ensure you place a file named index.html in the root of the www directory and this file will then be served instead.
